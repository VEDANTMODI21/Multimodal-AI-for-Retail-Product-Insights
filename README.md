## 📝 Overview

This repository contains the **complete codebase, training pipeline, hyperparameter tuning, and architecture** for **Multimodal AI for Retail Product Insights**. We propose a unified pipeline that fuses visual features (ViT), textual features (BERT), and structured transactional data to generate **actionable** human-readable business insights using a fine-tuned LLM.

### Key Contribution

Traditional retail analytics operates in unimodal silos — our framework bridges them:

```
Product Image    → ViT-Base/16  → h_v (768-d)  ─┐
Customer Reviews → BERT-base    → h_t (768-d)  ─┼─→ Concat+ReLU → h_f (512-d) → LLM → Actionable Insight
Structured Data  → MLP          → h_s (128-d)  ─┘
```

Each generated insight follows a **WHY → WHAT → HOW TO IMPROVE** structure — not just summaries, but root-cause analysis with concrete recommendations.

## 🔧 Technical Stack

| Component | Technology |
|-----------|------------|
| Visual Encoder | ViT-Base/16 (ImageNet-21k pretrained) |
| Text Encoder | BERT-base-uncased |
| Structured Processor | MLP + BatchNorm + Min-Max Scaling |
| Fusion | Concatenation + ReLU Projection + LayerNorm + Dropout |
| LLM (Dev/Lightweight) | DistilGPT-2 (~82M params) with LoRA (r=32, α=64) |
| LLM (Production) | Llama-2 7B with LoRA — requires HF token + ≥16GB VRAM |
| Framework | PyTorch 2.11+cu128 + AMP (Automatic Mixed Precision) |
| HPT | Optuna (TPE Sampler + Median Pruner, 15 trials) |
| Training GPU | NVIDIA RTX 5070 Laptop GPU (8GB VRAM, Blackwell SM_120) |
| Dataset | Amazon Review Dataset 2023 — Winter Clothing + Electronics |

## 🚀 Quick Start

### 1. Install Dependencies

```bash
pip install -r requirements.txt
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
```

### 2. Download & Prepare Dataset

Downloads the Amazon Review Dataset (2023), filters for winter clothing + electronics, downloads product images, and creates train/val/test splits. **Automatically starts training when done.**

```bash
python -m src.prepare_data
```

### 3. Train the Model (Manual)

Trains the full multimodal pipeline with AMP, validation, gradient clipping, cosine scheduler, and per-epoch checkpointing.

```bash
python -m src.train
```

### 4. Hyperparameter Tuning (Optuna)

Runs 15 Optuna trials (5 epochs each) with TPE sampling and median pruning, then auto-retrains with the best params for 25 epochs.

```bash
python -m src.tune
```

### 5. Evaluate

Generates insights on the test set and computes quality metrics (fluency, specificity, coherence, relevance).

```bash
python -m src.evaluate
```

### 6. Run Inference

```bash
python -m src.inference --image data/images/sample.jpg --review "Looks great but feels cheap" --price 89.99 --rating 2.8 --return_rate 0.4
```

### 7. Start API Server

```bash
python -m src.api
# POST /api/analyze with multipart form-data (image + review_text + price + rating + return_rate)
```

## 🎯 Insight Quality

Each generated insight follows a **3-sentence actionable format**:
1. **WHY** — Root cause analysis explaining the rating
2. **WHAT** — What specifically drove satisfaction or complaints
3. **HOW TO IMPROVE** — Concrete, actionable business recommendations

**Example output:**
> *"This mid-range winter apparel earns a strong 4.2-star rating primarily because customers consistently experience warm, comfortable, durable, which directly aligns with the product's marketed value proposition at $85. The positive sentiment is driven by accurate product imagery that sets realistic expectations, resulting in low return rates. To further capitalize on this momentum, the brand should leverage these positive reviews in targeted ad campaigns and consider introducing a premium variant at a 15-20% higher price point."*

## 🏗️ Architecture Highlights

- **Late Fusion** avoids early information loss while keeping inference fast (115ms/product)
- **LoRA Fine-Tuning** reduces trainable parameters by ~98% (7B → ~16M for Llama-2)
- **Anti-Modality-Dominance Dropout** (0.1) prevents the model from ignoring visual features
- **Encoder Freezing Strategy** — ViT and BERT frozen for first 2 epochs, then unfrozen at 0.1× LR
- **Gradient Accumulation** enables effective batch size of 32 on 8GB VRAM
- **Optuna HPT** — Automated hyperparameter search with TPE sampling and median pruning
